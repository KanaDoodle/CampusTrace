## 五项结果与兼容边界

1. **提醒读写状态收敛**：每次 Today 页面访问只共享一个读写 promise，重绘只替换当前绘制回调。写入进行时替换后的组件仍锁定，完成或失败只刷新当前组件，离开账号/页面不缓存迟到回复。新增写入中重绘、失败后重绘的回归，旧的读请求共享/错误重试用例继续通过。
2. **笔记保存共用去重流程**：普通界面使用 /api/documents/import。旧 POST /api/documents 和 Service.Ingest 保留完整 Document 返回格式，委托同一导入逻辑。普通、批量及复盘材料都在用户与来源范围按标题/正文去重；混合接口并发和响应丢失后的重试不会增加文档、片段或知识库版本。普通导入仍拒绝客户端伪造 origin。
3. **停止旧哈希向量写入**：新片段不再生成 128 维 lexical-hash，删除只为该写入服务的生成函数。保留 Chunk.Vector 可选字段、现有格式标记和旧 JSON 读取；真实语义向量、Cosine 和 knowledge_vectors 保留。用带旧向量的真实 SQL 记录验证读取与关键词结果一致，无数据迁移或删除。
4. **复盘来源仅在受锁事务内读取**：去掉事务外预读；持有用户锁后，一次联合查询读取同账号 interview/application/review 并校验 source_key，再写入文档/片段/资料版本。过期或跨账号来源拒绝写入，来源哈希格式保持一致。额外并发用例在请求执行期间持锁修正复盘，确认仍返回 stale 且文档数为 0。
5. **统一 Unicode 分段**：splitText 共用于生产入库、容量计算和离线 Dataset.Chunks；窗口 900、步进 700 不变。保留调用方的随机存储 ID 与确定性评测 ID。边界、重叠、尾部、中文/emoji，以及真实 SQL 入库与评测片段逐项一致均有覆盖。
