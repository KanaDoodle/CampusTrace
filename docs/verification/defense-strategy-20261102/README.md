## 保留的结果

[实验摘要](experiments.json)分别记录：

- **待人工审阅**：基线与候选各20例程序期望均满足，没有额外调用；评分保持空白，未采用。
- **调试集程序退化**：受控候选在一例中反复返回无效引用，程序期望未满足；在调试阶段拒绝，未运行验证集。
- **调用增加**：候选仍生成有效计划，但一例增加一次模型调用；准入拒绝。
- **验证集失败**：调试集通过后，候选在一例验证任务失败；保留结果，不反馈给提案模型继续调试。
- **无收益／语义退化／可采用门槛**：从同一批实际受控报告制作明确标为 `SYNTHETIC_CONTROL` 的评分夹具，分别验证无收益保留、局部退化不能被其他高分抵消，以及人工采用流程。这些是门槛测试，不是语义质量测量。

候选的实际系统提示哈希与基线不同，执行记录中的策略也与候选一致。报告中相同模型、任务、材料、框架、工具、代码和预算受到校验；不根据单条最终文字判定程序成功。所有执行使用现有20条合成答辩任务，新增控制分支只用于指定退化探针，不代表某种教学风格本身更差。

采用和回滚只在仓库外的验证注册表中进行；版本与历史保留，旧状态哈希不能覆盖新状态，产品拒绝加载验证专用注册表。正式注册表保持初始版本，未将合成评分用于产品采用。

## 人工审阅与证据范围

每个完整实验生成四份原评分格式的文件及逐题对照页。对照页包含共同任务、当前原回答、双方反馈、代码原文与轨迹，报告和材料哈希保持绑定；调试集来源报告与任务文件按原始字节归档。正式评分仍未审阅，不把模型自评或程序通过变成人工结论。

提案复用 `Model` 接口，本轮CLI只提供受控响应文件，单次选择受约束的候选。它没有创建提供商客户端，也不读取网页或本地模型密钥。真实评测报告可以通过现有授权CLI单独产生后导入，离线审阅与采用命令自身不发出模型请求。

本轮真实模型调用为0，原120次授权预算没有扩大。已验证的是执行、比较、审阅准入与回滚机制；未验证候选在真实回答上的反馈准确性、成本收益或学习提升。当前为有界的教学策略实验，没有训练模型或优化器自修改能力。

## 修正与后续

新增前的测试复现了候选未进入提示。实施中还修正了材料快照重新格式化会改变授权哈希的问题：现在归档原始字节，验收特意使用紧凑JSON任务验证这一点。初期实验与最终记录分开保留，早期快照不冒充最终版本。

最值得继续的一项是在新额度明确授权后，用少量真实回答和人工标注比较候选与基线，保留误判、无收益与退化；在此之前正式策略保持原版。本目录记录提交前的本地验收结果；发布状态以Git提交与Actions为准。
