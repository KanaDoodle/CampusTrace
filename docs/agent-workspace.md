# 已核对资料、记忆和 Go 练习

深度匹配使用你在求职资料中保存的内容，不回读未核对的原始简历。程序把不同学历、语言与技术、完整项目描述、项目要点和已确认事实组成一份可读正文；段落不拆句，也不替你润色或推断成果。“补充经历”用于保存解析遗漏的实习、科研等完整文字。求职偏好放在最后，明确不能证明能力。API 分析、同公司比较和 ChatGPT 分析包使用同一份正文，关键结论仍可按依据编号核对引用。

在「求职资料 → 查看已核对资料组成的完整分析正文」检查当前保存内容。编辑后先保存；分析前还会展示实际外发正文及完整岗位说明。资料变化会让旧报告待更新，旧分析包需重新导出。完整资料有助于减少上下文缺失，但不保证模型结论正确，也不会自动找回你取消导入的内容。

## 我的记忆与讨论记录

入口在「更多工具 → 求职问答」。

- **长期记忆**：手动添加、修改、遗忘求职偏好、已作决定和纠正记录；默认有效 180 天，每账号最多 100 条。可以问“记住：主投 Go 后端，优先上海”，Agent 只生成预览，点击确认才保存。它不会自动把岗位文案或推测变成记忆。
- **任务记忆**：每次问答保存问题、从成功工具结果生成的摘要、终态和调用次数；30 天内可选择“继续这次讨论”，也可删除摘要。问答中断保留运行终态，不自动重试付费请求或重放操作。
- **短期上下文**：同一会话保留最多 6 轮、30 分钟。修改资料或记忆后切换上下文版本；主动继续旧任务时，资料、记忆版本或有效记忆集合变化都会阻止旧摘要载入，并提示重新查询。

记忆不是学历、能力或岗位状态的证明。当前业务结论仍通过工具读取。上下文有大小上限，按问题选择最多 5 条相关记忆；Agent 可按关键词检索更多相关记忆。工具也只返回有界摘要。记忆、任务归属和版本由服务端校验，模型不能指定账号。修改采用版本检查；同一确认回执重复提交不会再次创建记忆。

遗忘会清空当前数据库中的记忆正文及其确认回执内容，删除旧任务摘要并清空常用任务检查点，切换记忆版本并清理短期会话。已经进行中的请求无法收回已发送文字，但其旧版本不能重新保存可继续的任务摘要。之前生成的本机数据库备份不会被改写。

使用外部问答模型时，有效记忆、你主动继续的讨论摘要及相关工具结果会发送给所选提供商。不要在记忆里填写联系方式或私密内容；联系方式校验、脱敏和补充姓名遮盖不能代替本人检查。

常用任务的逐步执行与恢复、外部资料连接、模型预算及招聘待办见 [求职助手说明](agent-harness.md)。

## 可选的 Go 练习

先启动主应用，再启用练习组件：

```sh
./campustrace practice start
./campustrace practice status
./campustrace practice stop
```

进入「更多工具 → Go 练习」。载入示例，或粘贴 `package exercise` 的实现和至少一个 `Test...` 用例，点击运行。支持页面列出的常用标准库，不下载第三方依赖。实现和测试各最多 24 KB；运行和用例合计最多 45 秒，用例超时 12 秒；每账号同时一条运行、每小时最多 20 次，执行器同时最多两条。

历史记录保存代码、测试及真实运行结果，可以重新载入修改。重复提交相同请求编号先返回原回执；相同编号但代码变了会被拒绝。页面网络失败后重试不会偷偷重复执行。服务中断的运行显示中断，需要主动发起新运行。练习通过只说明这些用例通过，不生成“有生产经验”的项目事实。问答读取最近练习时只返回最多五条状态与截短输出，代码和测试不作为工具上下文外发。

### 执行边界

`practice` 是可选 Compose profile，普通启动不启用。网页 API 没有 Docker socket；独立受信任的 `sandbox-runner` 控制器使用 Unix socket，内部签名请求不接受镜像、挂载、网络或启动命令等用户参数。控制器启动时清理自己标签下的残留容器，每次执行结束、取消或失败都会尝试销毁容器。

练习容器采用固定 `golang:1.25.9-bookworm` 镜像、普通用户、禁网、只读系统、无个人文件或 Docker socket 挂载、移除 capabilities、禁止新增权限，并限制 384 MB 内存、1 CPU、128 个进程/线程、临时目录大小和 16 KB 输出。源码与测试以固定文件名进入临时目录，编码后的内容作为独立参数，不拼入命令。语法和导入检查只是使用约束，真正的执行隔离由容器配置提供。

Docker 控制器持有宿主 Docker 权限，需要信任其代码和配置；这些限制适用于本机个人练习，不能宣称为公开多租户平台或虚拟机级隔离。参见 [Docker 安全文档](https://docs.docker.com/engine/security/)。非本机部署需设置独立、至少 32 字节的 `PRACTICE_SECRET`，并保持控制器不映射公网端口。

本机开发可设置 `PRACTICE_RUNNER_URL` 和相同 `PRACTICE_SECRET` 连接受信任执行器。默认容器部署已配置内部地址；不启用组件时，其他功能照常使用。

## 验证

```sh
node --test web/*.test.cjs
go test -race ./internal/agent ./internal/practice
RADAR_RACE=1 scripts/verify-radar.sh
# 明确启用真实 Docker 练习测试；只执行合成代码，不读取个人简历或调用模型。
CAMPUS_SANDBOX_INTEGRATION=1 go test -count=1 -v -run TestRealGoPracticeIsolation ./internal/practice
```

集成检查覆盖两个学历和完整项目正文、资料修正使旧输入失效、外发输入不重复项目、记忆确认与回执重放、并发版本冲突、遗忘、跨账号隔离、显式继续与旧摘要失效，以及练习幂等回执。真实容器检查普通用户、禁网、只读系统和密钥/socket 不可见，同时核对成功及失败用例状态。合成测试通过不代表外部模型在真实简历上的准确率。
