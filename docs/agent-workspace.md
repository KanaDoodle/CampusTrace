# 已核对资料与记忆

深度匹配使用你在求职资料中保存的内容，不回读未核对的原始简历。程序把不同学历、语言与技术、完整项目描述、项目要点和已确认事实组成一份可读正文；段落不拆句，也不替你润色或推断成果。“补充经历”用于保存解析遗漏的实习、科研等完整文字。求职偏好放在最后，明确不能证明能力。API 分析、同公司比较和 ChatGPT 分析包使用同一份正文，关键结论仍可按依据编号核对引用。

在「求职资料 → 查看已核对资料组成的完整分析正文」检查当前保存内容。编辑后先保存；分析前还会展示实际外发正文及完整岗位说明。资料变化会让旧报告待更新，旧分析包需重新导出。完整资料有助于减少上下文缺失，但不保证模型结论正确，也不会自动找回你取消导入的内容。

## 我的记忆与讨论记录

入口在「更多工具 → 求职问答」。

- **长期记忆**：手动添加、修改、遗忘求职偏好、已作决定和纠正记录；默认有效 180 天，每账号最多 100 条。可以问“记住：主投 Go 后端，优先上海”，Agent 只生成预览，点击确认才保存。它不会自动把岗位文案或推测变成记忆。
- **任务记忆**：每次问答保存问题、从成功工具结果生成的摘要、终态和调用次数；30 天内可选择“继续这次讨论”，也可删除摘要。问答中断保留运行终态，不自动重试付费请求或重放操作。
- **短期上下文**：同一会话保留最多 6 轮、30 分钟。修改资料或记忆后切换上下文版本；主动继续旧任务时，资料、记忆版本或有效记忆集合变化都会阻止旧摘要载入，并提示重新查询。

记忆不是学历、能力或岗位状态的证明。当前业务结论仍通过工具读取。上下文有大小上限，按问题选择最多 5 条相关记忆；Agent 可按关键词检索更多相关记忆。工具也只返回有界摘要。记忆、任务归属和版本由服务端校验，模型不能指定账号。修改采用版本检查；同一确认回执重复提交不会再次创建记忆。

遗忘会清空当前数据库中的记忆正文及其确认回执内容，删除旧任务摘要并清空常用任务检查点，切换记忆版本并清理短期会话。已经进行中的请求无法收回已发送文字，但其旧版本不能重新保存可继续的任务摘要。之前生成的本机数据库备份不会被改写。

使用外部问答模型时，有效记忆、你主动继续的讨论摘要及相关工具结果会发送给所选提供商。不要在记忆里填写联系方式或私密内容；联系方式校验、脱敏和补充姓名遮盖不能代替本人检查。

常用任务的逐步执行与恢复、外部资料连接、模型预算及招聘待办见 [求职助手说明](agent-harness.md)。
